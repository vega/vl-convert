# CLI Reference

Start the server with `vl-convert serve`. Global converter options can appear before or after `serve`. Server-specific options must follow it:

```text
vl-convert [GLOBAL OPTIONS] serve [SERVER OPTIONS]
```

The help below is generated from the executable used to build the documentation. See {doc}`overview` for a startup example and {doc}`advanced/configuration` for configuration files and environment variables.

## `serve`

```{program-output} python ../tools/run_vl_convert.py serve --help
```

# VlConvert Logo

`vl-convert-logo.svg` is the VlConvert mark: the Vega "V" followed by a block
letter "C" in the style of the Vega-Lite "VL" logo. `vl-convert-favicon.svg` is
the same mark centered in a square viewBox.

The two blue strokes, the shadow slivers, and the colors are taken verbatim from
the Vega-Lite logo in the [vega/logos](https://github.com/vega/logos)
repository, which is BSD-3-Clause licensed by the Vega project. The yellow "C"
is drawn on the same 48 unit grid: 11 unit spine, arms, and terminals, 5 unit
chamfers on the outer corners, and a 4 unit step at the tips.

The Sphinx configuration in `docs/source/conf.py` references these files
directly, and the docs build copies them into the output `_static/` directory.

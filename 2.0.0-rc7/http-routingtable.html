HTTP Routing Table

/admin | /bundling | /healthz | /infoz | /readyz | /svg | /themes | /vega | /vegalite
 
/admin
GET /admin/budget Return the active request-budget settings and state.
GET /admin/config Return the startup configuration, active configuration, and generation number.
GET /admin/config/fonts/cache Return the Google Fonts cache capacity and read-only directory.
GET /admin/config/fonts/directories Return the currently-registered font directories.
GET /admin/diagnostics/workers Return JavaScript memory statistics for each conversion worker.
POST /admin/budget Update selected request-budget settings.
POST /admin/config/fonts/directories Append a single font directory. Idempotent for already-registered paths.
PUT /admin/config Replace the complete active converter configuration.
PUT /admin/config/fonts/cache Set the Google Fonts cache capacity. `{"max_size_mb": null}` restores the default capacity. The directory is read-only and cannot be set here.
PUT /admin/config/fonts/directories Replace the full font-directory list. Pass `{"paths": []}` to clear.
DELETE /admin/config Restore the converter configuration that the server started with.
PATCH /admin/config Update selected fields in the active converter configuration.
 
/bundling
GET /bundling/bundle Return a browser bundle containing Vega, Vega-Lite, and Vega Embed.
POST /bundling/bundle-snippet Bundle an application snippet with compatible visualization dependencies.
 
/healthz
GET /healthz Report whether the server process is running.
 
/infoz
GET /infoz Return server and bundled visualization-library version information.
 
/readyz
GET /readyz Report whether the converter can accept requests.
 
/svg
POST /svg/jpeg Convert an SVG document to a JPEG image.
POST /svg/pdf Convert an SVG document to a PDF document.
POST /svg/png Convert an SVG document to a PNG image.
 
/themes
GET /themes List the available Vega themes.
GET /themes/{name} Return one Vega theme configuration.
 
/vega
POST /vega/fonts Return the fonts that VlConvert resolves for a Vega specification.
POST /vega/html Convert a Vega specification to an interactive HTML page.
POST /vega/jpeg Convert a Vega specification to a JPEG image.
POST /vega/pdf Convert a Vega specification to a PDF document.
POST /vega/png Convert a Vega specification to a PNG image.
POST /vega/scenegraph Evaluate a Vega specification and return its scenegraph.
POST /vega/svg Convert a Vega specification to an SVG document.
POST /vega/url Create a Vega Editor URL for a Vega specification.
 
/vegalite
POST /vegalite/fonts Return the fonts that VlConvert resolves for a Vega-Lite specification.
POST /vegalite/html Convert a Vega-Lite specification to an interactive HTML page.
POST /vegalite/jpeg Convert a Vega-Lite specification to a JPEG image.
POST /vegalite/pdf Convert a Vega-Lite specification to a PDF document.
POST /vegalite/png Convert a Vega-Lite specification to a PNG image.
POST /vegalite/scenegraph Compile and evaluate a Vega-Lite specification, then return its scenegraph.
POST /vegalite/svg Convert a Vega-Lite specification to an SVG document.
POST /vegalite/url Create a Vega Editor URL for a Vega-Lite specification.
POST /vegalite/vega Compile a Vega-Lite specification to Vega.

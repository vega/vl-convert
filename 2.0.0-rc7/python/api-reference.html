Python Sync API Reference#

This page documents the synchronous vl_convert module. For vl_convert.asyncio, see Python Async API Reference.

These entries are generated from the version 2 type stubs. Vega and Vega-Lite specifications may be passed as JSON strings or dictionaries. PNG, JPEG, and PDF functions return bytes. SVG, HTML, and URL functions return str. Scenegraph functions return a dict by default, or MessagePack bytes with format="msgpack".

Start with Quick Start if you are choosing a conversion function for the first time.

JavaScript Bundling#

vl_convert.javascript_bundle(snippet: str | None = None, *, vl_version: str | None = None) → str#

Create a JavaScript bundle containing Vega, Vega-Lite, and Vega Embed.

An optional snippet can refer to Vega Embed as vegaEmbed, Vega-Lite as vegaLite, Vega as vega, and lodash.debounce as lodashDebounce.

The result includes these libraries and their dependencies. It can be used in an HTML <script> tag without loading another JavaScript file. The default snippet assigns vegaEmbed, vegaLite, and vega to the global window object, making them available to other script tags.

Parameters:

  • snippet – JavaScript source to bundle. Imports must refer to dependencies already bundled with VlConvert.

  • vl_version – Bundled Vega-Lite version, such as "6.4". The default is the newest version bundled with this release.

Returns:

JavaScript bundle as a string.

vl_convert.google_fonts_cache_dir() → str | None#

Return the path of the on-disk Google Fonts cache directory.

Resolved once per process from the environment:

  1. VLC_GOOGLE_FONTS_CACHE_DIR=none: None (caching disabled, fonts always fetched fresh).

  2. VLC_GOOGLE_FONTS_CACHE_DIR=/some/path: that path.

  3. Unset: the OS cache directory joined with vl-convert/google-fonts (e.g. ~/Library/Caches/vl-convert/google-fonts on macOS).

The value is fixed for the lifetime of the process. There is no runtime setter.

Returns:

Absolute path to the Google Fonts cache directory, or None if caching is disabled.

vl_convert.google_fonts_cache_size_mb() → int#

Return the active capacity of the on-disk Google Fonts cache.

The capacity is shared by every converter in the process. It starts at 512 MB and changes when set_google_fonts_cache_size_mb() is called.

Returns:

Active capacity in megabytes. The value is always positive.

vl_convert.set_google_fonts_cache_size_mb(max_size_mb: int | None) → None#

Set the capacity of the on-disk Google Fonts cache.

None restores the default capacity of 512 MB. Cached fonts over the new limit are evicted immediately. The setting affects every converter in the process.

Parameters:

max_size_mb – New capacity in megabytes. Use None for the default. Positive integers are accepted. Passing 0 raises ValueError.

Configure defaults and resource policies for subsequent conversions.

Parameters:

  • num_workers – Worker count (must be >= 1). None resets to the built-in default (1). Passing 0 raises ValueError.

  • base_url – Base URL for resolving relative data and image paths in Vega specs. None or True resets to the default (vega-datasets CDN). False disables relative path resolution. A string sets a custom base URL or filesystem path.

  • allowed_base_urls – CSP-style allowlist for data and image access (HTTP URLs, filesystem paths). Examples: "https:" (scheme), "https://example.com/" (prefix), "/data/" (filesystem), "*" (everything). None resets to the default (["http:", "https:"]). [] blocks all absolute data and image locations.

  • auto_google_fonts – Automatically download missing fonts from Google Fonts. None resets to the built-in default (False).

  • embed_local_fonts – Embed locally available fonts as base64-encoded data URIs in SVG and HTML output. PNG and JPEG contain rendered pixels, and PDF output is self-contained. None resets to the default (False).

  • subset_fonts – Subset fonts to only the characters used in the chart. Applies to SVG and HTML output. None resets to the built-in default (True).

  • missing_fonts – Missing-font behavior: "fallback" (silent), "warn", or "error". None resets to the built-in default ("fallback").

  • google_fonts –

    Google Fonts to register for all subsequent conversions. Each entry is a family-name string or a dict with "family" (required) and optionally "variants" (list of (weight, style) tuples). Fonts are downloaded and registered on each conversion call.

    Replace semantics. Each call to configure(google_fonts=[...]) replaces the full configured list. None (or []) resets to the built-in default (empty list).

  • google_font_variant_threshold – Once the number of resolved Google Font variants reaches this threshold, the next font request fails the conversion. Configured, per-call, and automatically discovered families all count. A single request can take the total above the threshold. Must be >= 1 if provided. None resets to the built-in default (no cap). Passing 0 raises ValueError.

  • max_v8_heap_size_mb – Maximum JavaScript (V8) heap size per worker in megabytes. Must be at least 64 if provided, the smallest heap V8 accepts. None resets to the built-in default (no cap). Passing 0 raises ValueError, and values below 64 raise ValueError when the converter is built.

  • max_v8_execution_time_secs – Maximum JavaScript (V8) execution time in seconds. Must be >= 1 if provided. When exceeded, JavaScript execution stops and the conversion returns an error. None resets to the built-in default (no cap). Passing 0 raises ValueError.

  • gc_after_conversion – Whether to run JavaScript garbage collection after each conversion. This can reduce retained heap but adds work. None resets to the default (False).

  • vega_plugins – List of Vega plugins to load. Each entry is a file path (.js/.mjs), URL (https://...), or inline ESM string. Plugins must be single-entry ESM modules with a default export function accepting a vega object. Multi-file plugins should be pre-bundled with esbuild or Rollup. URL plugins auto-allow their domain for imports. None (or []) resets to the built-in default (empty list).

  • plugin_import_domains – Domain patterns allowed for HTTP imports inside config-level plugins. Use ["*"] for any domain, or ["esm.sh", "*.jsdelivr.net"]. None (or []) resets to the built-in default, an empty list that disables HTTP imports.

  • allow_per_request_plugins – Whether to accept per-request plugins via the vega_plugin parameter on conversion functions. None resets to the built-in default (False).

  • max_ephemeral_workers – Maximum temporary JavaScript workers for concurrent per-request plugins. Must be >= 1 if provided. None resets to the default (2). Passing 0 raises ValueError.

  • allow_google_fonts – Server policy for accepting google_fonts in HTTP request bodies. It does not restrict direct Python calls. None resets to the default (False).

  • per_request_plugin_import_domains – Domain patterns allowed for HTTP imports inside per-request plugins. Separate from plugin_import_domains. None (or []) resets to the built-in default, an empty list that disables HTTP imports.

  • default_theme – Default named theme (e.g. "dark") applied to all Vega-Lite conversions. Per-request theme overrides this if set. None resets to the built-in default (no theme).

  • default_format_locale – Default d3-format locale name or dictionary applied to all conversions. Per-request format_locale overrides this if set. None resets to the built-in default (no locale).

  • default_time_format_locale – Default d3-time-format locale name or dictionary applied to all conversions. Per-request time_format_locale overrides this if set. None resets to the built-in default (no locale).

  • themes – Custom named themes mapping names to Vega config objects. Registered alongside built-in vega-themes. Custom themes take priority over built-in themes if names collide. None (or {}) resets to the built-in default (empty map).

GoogleFontSpec#

The google_fonts parameter accepts family-name strings or GoogleFontSpec dictionaries. A dictionary names a family and optional variants:

{
    "family": "Inter",
    "variants": [(400, "normal"), (700, "italic")],
}

FontInfo#

The dictionary returned for each font by vegalite_fonts() and vega_fonts(). It contains the font name, source, variants, and optional CSS helpers for Google-hosted fonts.

class FontVariant(TypedDict):
    weight: str
    style: str
    font_face: str | None

class FontInfo(TypedDict):
    name: str
    source: FontSource
    variants: list[FontVariant]
    url: str | None
    link_tag: str | None
    import_rule: str | None

FontSource identifies whether the font comes from Google Fonts or a local file:

class GoogleFontSource(TypedDict):
    type: Literal["google"]
    font_id: str

class LocalFontSource(TypedDict):
    type: Literal["local"]

FontSource: TypeAlias = GoogleFontSource | LocalFontSource
